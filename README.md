# GIFTORA

Mobile-first Telegram digital gifts experience.

## Stack
- React + TypeScript + Vite
- TON Connect UI (wallet integration foundation)
- Telegram Mini Apps SDK (integration foundation)

## Development
```bash
npm install
npm run dev
```

## Current scope
The first commit establishes the responsive glass-style interface and catalog prototype. Gift entries and displayed TON values are mock presentation data only; they do not represent live listings, ownership, or on-chain transactions.

## Network
The initial development target is TON Testnet. Official Telegram collectible gift availability and real asset ownership must be verified through authoritative Telegram/TON data before showing them as live assets.
